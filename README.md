# IBM-Project
SolarROI AI

AI-powered renewable energy investment feasibility assistant, built for the 1M1B AI for Sustainability Virtual Internship (in collaboration with IBM SkillsBuild & AICTE).

SolarROI AI helps homeowners and MSMEs evaluate whether a rooftop solar installation is financially worthwhile — combining a financial payback/IRR calculator with a Retrieval-Augmented Generation (RAG) pipeline over official government subsidy policy documents.

SDG Alignment: SDG 7 (Affordable and Clean Energy), SDG 12 (Responsible Consumption and Production)

How it works
  1.A financial calculator computes net cost, payback period, and IRR from the user's system cost, subsidy %, and expected monthly savings.
  2.Subsidy policy PDFs (MNRE, PM Surya Ghar, Gujarat SURYA scheme) are chunked and embedded into a searchable FAISS index.
  3.A retrieval step pulls the most relevant subsidy/eligibility text for the user's query.
  4.IBM Granite (run locally) combines the calculated numbers and retrieved policy context into a plain-language feasibility report.

data/ contains the input documents the pipeline reads from — the subsidy policy PDFs it retrieves from.
outputs/ contains sample results generated by the pipeline — example feasibility reports for a few test scenarios, useful for reviewing the project's output without re-running the notebook.

AI components used
Component	Role
IBM Bob	Primary AI development tool — used throughout to write, debug, and refine the Python pipeline code
IBM Granite	Core language model (run locally), used for grounded Q&A and report generation
Retrieval-Augmented Generation (RAG)	Retrieves relevant subsidy policy text before generation
Prompt engineering	Grounds every generated answer strictly in retrieved context
Agentic AI workflow	Chains the calculator, retrieval, and generation steps into one automated pipeline
Entity extraction & summarization	Extracts subsidy details from retrieved text and summarizes into the final report

Setup
pip install -r requirements.txt

Open code.ipynb and run all cells in order. The IBM Granite model downloads automatically on first run (cached locally afterward — no repeated downloads or API calls needed).

Responsible AI
Transparency: Every report is grounded in retrieved source text and explicitly calculated figures, not the model's unverified claims.
Fairness: The same process applies regardless of system size or location.
Ethics: This is a decision-support tool, not financial advice.
Privacy: No personal or sensitive user data is collected or stored.
